# Tasklist

This is a simple tasklist made in vue and ionic, to work in mobile devices.

# Setup

1. Make sure you have [Node.js](https://nodejs.org/) installed.

2. Install the Ionic CLI globally by running:
   ```bash
   npm install -g @ionic/cli
   ```

3. Clone this repository to your local machine.

4. Navigate to the project directory.

5. Install the project dependencies by running:
   ```bash
   npm install
   ```

6. Start the development server with:
   ```bash
   ionic serve
   ```

7. Open your browser and go to `http://localhost:8100` to view the app.
